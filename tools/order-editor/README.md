# Локальный редактор порядка работ

Нужны Node.js ≥ 20 и Hugo **extended ≥ 0.166.0**, как для сборки сайта. Дополнительные пакеты не нужны.

На Windows можно запустить из PowerShell без `node` в PATH:

```powershell
.\tools\order-editor\start.cmd
```

Этот launcher сначала ищет системный Node.js, затем локальный `.tools/node/node.exe`. Для Hugo используется PATH, переменная `HUGO_BINARY` или локальный `.tools/hugo/hugo.exe`. На текущем компьютере подготовлены локальные копии обоих инструментов; устанавливать их в систему не требуется. Каталог `.tools/` исключён из Git и не переносится при клонировании репозитория. Параметры `--hugo` и `--port` можно передать и в `start.cmd`.

Из корня проекта:

```powershell
node tools/order-editor/server.mjs
```

Открыть адрес из терминала: **http://127.0.0.1:1314/**. Остановка — `Ctrl+C`.
Если Hugo не находится в PATH, указать исполняемый файл:

```powershell
node tools/order-editor/server.mjs --hugo "C:\tools\hugo.exe"
```

Также поддерживаются переменная `HUGO_BINARY` и `--port 1315` для другого порта.

## Работа

1. Выбрать «Дизайн», «Живопись», «Графика» или «Миниатюры».
2. Перетаскивать изображения перед/после других. Изображение следует за курсором, соседи плавно освобождают ему место ещё до отпускания мыши. Пунктир показывает будущую позицию; у края окна включается прокрутка. `Esc` отменяет текущий перенос. Карточки показывают только изображения, без подписей и кнопок. Последовательность идёт слева направо по трём колонкам; высота изображений разная, как на сайте, и колонки заполняются независимо.
3. Нажать на изображение, чтобы открыть существующую подпись. Изменить текст и нажать «Применить». `Enter` или пробел на карточке также открывает редактор; `Esc` и «Отмена» закрывают его без применения. Перетаскивание окно не открывает.
4. Нажать «Сохранить изменения» для текущего раздела, чтобы записать порядок и подписи в файлы. На общей панели доступны отмена последнего действия и сброс; они работают и для перестановок, и для подписей. Черновики других разделов сохраняются при переключении вкладок; каждый раздел сохраняется отдельно.
5. Просмотреть `git diff`, затем коммитить и публиковать обычным способом.

«Обновить список» заново читает проект через Hugo — использовать после добавления/удаления работ или внешних правок файлов. Несохранённые изменения при этом сбрасываются после подтверждения. Перезагрузка/закрытие страницы также теряет черновики; браузер предупреждает об этом.

## Что сохраняется

При перестановке редактор меняет число в строке `weight:` YAML front matter; при редактировании подписи — текст в `alt:`. Если изменены только подписи, веса сохраняются. Остальные поля (включая `title`), комментарии, кодировка и окончания строк сохраняются. Подпись должна быть непустой, до 2000 символов; кавычки, двоеточия и переносы строк автоматически экранируются для YAML. Веса при перестановке назначаются с шагом 10 по убыванию: **больший вес идёт раньше**, как в существующей теме. Дополнительного файла порядка нет. Общая галерея и мобильная версия следуют получившимся весам и подписям.

Состав работ, миниатюры, EXIF-поворот и начальная последовательность берутся из Hugo, включая разрешение равных весов. Перед сохранением редактор проверяет, что файлы и состав раздела не изменились с момента загрузки. При конфликте нужно обновить список. Новые работы, обнаруженные кнопкой «Обновить список» в открытом редакторе, добавляются в конец черновика: новый порядок нужно сохранить. При первом запуске позиция всех работ определяется текущими весами Hugo.

Редактор слушает только `127.0.0.1`. Миниатюры и служебный JSON создаются во временной папке, которая удаляется при штатной остановке. Локальный конфиг `tools/order-editor/hugo.yaml` включает дополнительный JSON-вывод; обычная сборка и CI его не используют. Код редактора расположен вне `static/` и не попадает на опубликованный сайт. Отдельный `hugo server` для редактора не нужен; его можно запустить параллельно для предпросмотра сайта.

## Проверки

```powershell
node --test tools/order-editor/store.test.mjs
```

Полная проверка с пересборкой настоящего сайта и перестановкой всех разделов в **временной копии контента**:

```powershell
$env:HUGO_BINARY = "C:\tools\hugo.exe"
node --test tools/order-editor/store.test.mjs
```
